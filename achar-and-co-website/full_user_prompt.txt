## 7. AUTOMATIC UNIQUE ORDER ID GENERATION

Automatically generate a unique Order ID when the customer successfully submits the frontend order form.

### Order ID Format

Use:

ACH-YYYY-XXXXXXXX

Examples:

- ACH-2026-A7F29C81
- ACH-2026-B82D4F19
- ACH-2026-C91E6A32

Requirements:

- Use the current year automatically.
- Use the browser's secure crypto.randomUUID() API to generate the random identifier.
- Format the identifier as an eight-character uppercase alphanumeric segment.
- Use a sufficiently large random space and check against existing locally stored IDs to minimize collisions.
- Do not use Math.random() or timestamps alone.
- Generate a new Order ID for each new valid submission.
- Do not generate another Order ID when the same confirmation popup is reopened.
- Prevent duplicate order creation from double-clicking Submit.
- Use one Order ID for a shopping bag checkout containing multiple products.
- Use one Order ID for each Pick Any Three combo order.

This is frontend-only ID generation. It does not guarantee globally unique IDs across all customer browsers.
